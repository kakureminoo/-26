# 光と影の猟犬

3D表示・2Dマス制のブラウザゲーム。URLからPC・スマホで遊ぶ構成です。

## 起動

Node.js 22.12以降とnpmを使用します。

```sh
npm ci
npm run dev
```

表示されたlocalhostのURLを開きます。`index.html`の直開きでは動作しません。

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run preview
```

`dist/`が公開用ファイルです。HTTPSの静的ホスティングに配置できます。公開先のアカウント・URLは未設定です。

## 明暗・連携・敵の予告

ラウンドの最初に「光から／影から」を選べます。移動または移動省略を確定した後は順番を変更できません。二匹が一回ずつ行動してから敵の手番へ進みます。

敵はラウンド開始時に行動を予告し、こちらの操作後も狙うマスを変更しません。赤い斜線は攻撃、青い矢印は移動です。盤面の「敵の予告」を開くと詳細を確認できます。移動先を塞ぐ、射線を遮る、射撃する敵を暗くすることで対処できます。

- **影鎧兵**: 明るさ0〜1で防御2。照らすと解除。
- **灯射兵**: 明るさ3〜4で直線4マスへ射撃。暗くすると中止し、遮蔽物ではその手前までに短縮。

ホームの「明暗の連携を練習する」から、固定能力の演習を最初から遊べます。育成・装備・素材・物語の進行と報酬には影響しません。演習で影から遮蔽物を置く、光で灯火を移す、といった連携を試せます。

複数目標を同時に守るステージ、装備による位置交換などの固有コマンド、成長上限の追加は今回の範囲に含めていません。

戦術更新の検証結果：型検査・ビルド成功、ルール24件・ブラウザ31件成功。通常4クエストの通し確認はPCの強化データで実施。固定能力の演習は3画面サイズでクリアし、保存データが変わらないことを確認しました。本番用ビルドでも起動・行動順・射撃・防御・次ラウンドを確認済みです。スマホ実機性能と本編の通常難易度の調整は未実施です。

## 仲間・対戦・レイド（2026-10-19）

本編は3段階、猟犬8種、猟犬召喚、達成ミッション、周回遠征を追加しました。拠点の「仲間」から編成・召喚・ミッションを開けます。最終ボス討伐後は「クエスト → エンドコンテンツ」から周回遠征・闘技場・レイドへ進めます。詳細は[仕様](docs/social.md)、[検証結果](docs/quality.md)を参照してください。

オンライン機能は二つのターミナルで起動します。

```sh
# ターミナル1：ゲーム画面
npm run dev

# ターミナル2：対戦・レイド用サーバー
npm run server
```

通常の接続先は/api/play（Viteが127.0.0.1:8787へ転送）。最終ボス討伐済みの同じPCの別ブラウザまたは別プロフィールでゲームを開き、片方で部屋を作り、もう片方で部屋コードを入力します。オンライン画面から接続先を変更できます。CPU対戦・CPU共闘にはサーバーは不要です。

```sh
# 一時データを使った複数クライアント実通信・レート保存・レイド検証
npm run test:server
```

サーバー設定：PLAY_PORT（既定8787）、PLAY_HOST（既定127.0.0.1）、PLAY_DATA_DIR（既定server/data）、PLAY_ORIGINS（許可する画面のオリジンをカンマ区切り）。LANで試す場合はゲームとサーバーの待受を設定し、画面URLのオリジンを許可します。開発用サーバーを公衆回線へ公開する設定ではありません。

ゲストIDはブラウザと接続先ごとに保存します。server/data/accounts.jsonはゲスト認証情報・レート・報酬を含むためGit対象外です。レートは再起動後も残りますが、進行中の部屋は消えます。distだけではオンラインAPIを配信できません。公開サーバー・共通ログイン・所持権のサーバー管理は未導入です。
