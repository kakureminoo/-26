# 三段階クエスト・仲間・対戦・レイド

2026-10-19追加。既存のlightShadowSave/lightShadowAudioと全25クエストの達成ID、育成値、装備、刻印、素材を保持する。

## 本編の三段階

全25クエストは同じ戦場で前哨戦→増援→最終目標の三段階。最初の二段階は守兵の討伐、最後は元の討伐・ボス討伐・物資回収・救助条件。最初から物資・救助対象を回収して段階を飛ばすことはできない。元データを変更せず、game/quest-stages.tsから戦闘用の写しを作る。

- 前哨戦1体（元HPの45%、最低2）、増援2体まで（55%、最低2）、最後は元の敵構成。守兵がいない場合はボスの配置を元に通常守兵を作る。
- HP、配置、チャージ、壊れた遮蔽物を引き継ぐ。段階間で生存する犬だけ最大HPの20%を回復し、行動順を選び直す。倒れた犬は復活しない。増援は犬と重ならない床へ配置する。
- 各段階の開始にステージ名を表示。三段階目の達成時だけ既存報酬・進行・召喚石を付与する。途中の失敗・撤退は報酬なし。戦闘中断の保存は未対応。
- 固定演習と既存エンドコンテンツは本編三段階化の対象外。固定演習のプロフィール不変・報酬なしを維持する。独立した周回遠征は三波の全滅が条件。

## 猟犬8匹

初期二匹＋物語加入二匹＋召喚限定四匹。光一匹・影一匹を編成し、拠点と本編に反映する。育成・装備は従来の光/影枠で共有、固有特性を加算する。対戦は二匹が異なれば属性の組合せを制限しない。名前は犬のIDごとに保存し、初期二匹は旧nameも互換のため維持する。正本はgame/roster.ts。

| 猟犬 | 加入 | 固有特性 |
| --- | --- | --- |
| 黎明／光 | 初期 | 追加補正なし |
| 宵／影 | 初期 | 追加補正なし |
| 城衛のアウル／光 | 灯台の要所bossクリア | HP+4、防御+1、移動−1 |
| 森守のノクス／影 | forest-heartクリア | 移動+1、HP−2 |
| 陽炎のレグルス／光 | 召喚限定 | 明3以上で攻撃+2、HP−2 |
| 月牙のセレネ／影 | 召喚限定 | 暗1以下で攻撃+2、HP−2 |
| 燎原のイグニス／光 | 召喚限定・希少 | 攻撃+1、防御−1 |
| 霜影のフェン／影 | 召喚限定・希少 | HP+6、移動−1 |

猟犬は自作の体格・耳・装飾で8体を区別する。現行モデルとレア度の詳細は末尾の「自作猟犬・レア度付き召喚」を参照。

## 猟犬召喚と報酬

刻印とは別に「猟犬召喚石」を使う。1回10、10回100。通常の割合はレグルス40%、セレネ40%、イグニス10%、フェン10%。希少が9回続けて出なければ10回目は希少各50%。希少取得で保証カウンタをリセット。重複は絆の欠片20になり、100で未所持の限定猟犬を指名交換できる。既所持の交換や、不足・無効な乱数での消費を拒否する。

- 本編：初回10石／再クリア3石。通常の非固定エンドクエストも初回10／再3。
- 周回遠征「欠片の鉱脈」：最終ボス討伐で開放。三波クリアで毎回8石。回数・スタミナ制限なし。既存の欠片報酬は初回6／再2。
- ミッションは受取ボタンで一度だけ付与。旅支度10、クエスト1回10、クエスト3回20、周回5回30、CPU対戦3勝30、レイド1回50。過去の勝利を石へ一括変換しない。
- CPUレイド成功：20石＋灯の欠片8。オンラインレイド成功：50石＋灯の欠片20。途中退出を除く参加者全員が対象。オンラインの報酬IDを照合し、再接続でも二重加算しない。
- 固定演習・固定能力試練で新しい猟犬特性を持ち込まない。固定試練に猟犬召喚石は付与しない。課金なし。

## 闘技場

最終ボス討伐後のエンドコンテンツ。CPU戦とオンライン戦に対応する。7×7の専用盤面を使い、全員Lv.5の固定基礎値（HP28・攻撃6）、装備・刻印・訓練・解放補正なし。固有特性と現在地の明暗は反映する。自分の所持猟犬から異なる二匹を選ぶ。召喚限定の猟犬を禁止する制限はない。

各ラウンド、各チームの最初の行動前に先に動く猟犬を選べる。各チーム一匹ずつ交互に動く。手番は移動一回＋技一回。現在地クリックは移動を消費しない。通常攻撃は隣接、貫通の牙は同じ行・列の射程4・チャージ2。アウル/フェンは代わりに周囲3マスの仲間のHPを5回復し、防御する。明暗の技は自身と隣接4マスを光4／影0へ変える。チャージはチームごと最大3、ラウンドごと1回復。

オンラインの勝敗・操作権・座標・移動コスト・チャージ・HP・手番はサーバーが判定し、古いrevisionの要求を拒否する。レートは初期1000、Elo K=24、同点同士の勝敗は±12。CPU戦はオンラインのレートに影響しない。退出は敗北、双方のレート更新は一度だけ。ゲストIDとレートはserver/data/accounts.jsonへ保存し、サーバーを再起動しても保持する。

## レイド

オンラインは1〜4人、一人一匹。部屋主が開始する。開始後の参加・編成変更なし。ボスHPは人数×45、犬の基礎HP32に固有特性を加算。ボスへの通常攻撃は射程3。全参加者の手番後に、開始時から示した一列へボス攻撃が来る。明暗変更または移動で備える。奇数ラウンドの夜蝕は明るさ3〜4、偶数の白灼は0〜1で防ぐ。予告はラウンド中固定で、危険表示・CPUの避難・実命中のすべてがgame/tactics.tsのassessPlanを参照する。安全になった予告マスは青緑、危険は赤の斜線で区別する。CPU共闘は自分一匹＋CPU三匹として区別して表示する。

オンラインは手番45秒で自動防御、60ラウンド上限。リロード時は同じゲストIDで接続し、参加中の部屋へ復帰する。犬が倒れても、途中退出しなければ討伐報酬を受け取れる。サーバー再起動時は進行中の部屋を復元せず、未決着のレートを変更しない。

## 起動と制約

端末1で `npm run dev`、端末2で `npm run server`。Vite開発サーバーの/api/playを127.0.0.1:8787へ転送する。接続先はオンライン画面から変更できる。通常は同じPCの別ブラウザ・別プロフィールで接続する。ゲストIDはブラウザと接続先ごとに保存する。

ローカル実装であり、公開サーバー・HTTPS・永続ホスティング・共通ログイン・本番の不正対策や負荷対策は未導入。所持品と本編の開放条件は現在ローカル保存を参照し、サーバーはキャラクターIDと戦闘能力を検証するが、召喚履歴や所持権をサーバー側で管理してはいない。レート対戦の公開運用前には所持権の管理を移す必要がある。

新しい依存ライブラリ・外部素材の追加なし。Node.js組込HTTP・暗号乱数・ファイル保存と、既存のThree.jsを使用する。実機タッチ、四人の人間での連携、公開回線、通常育成での全25クエスト三段階の通し難易度は未検証。

## 2026-10-19：自作猟犬・レア度付き召喚

- 猟犬は外部GLBを読み込まず、`render/hound-model.js`と`render/hound-design.ts`のオリジナル手続き生成モデルを使用。8体で体格、耳、たてがみ、装甲・角・結晶などの造形を変更する。戦闘・拠点・編成サムネイルは同じ造形を参照する。旧GLBファイルと出典は履歴用に残すが、現行ビルドに含めない。
- 編成画面は一つの共有WebGLコンテキストで8体を撮影した画像を表示。未加入でも外観を確認できる。自作モデルは現段階の造形であり、市販作品と同等の品質を検証・保証したものではない。
- 通常排出率：星5猟犬2%（イグニス・フェン各1%）、星4猟犬8%（レグルス・セレネ各4%）、星3お守り30%（6種類各5%）、星2結晶30%（2個）、星1鉄材30%（3個）。初期・物語加入の猟犬は星4。
- 星5以外が50回連続したら次の51回目は必ず星5（2体各50%）。星4ではカウントをリセットしない。10連も1回ずつ同じルールを適用する。残回数と提供割合を表示する。星4の別枠保証はない。
- セーブversion2への移行で所持・名前・編成・石・絆・累計回数を保持。旧`dry`がある場合は旧10回保証までの残り回数を一度だけ保持し、星5獲得時に終了する。新規セーブは51回保証から開始する。
- 猟犬重複は絆20、所持済み装備重複は鉄材2。装備は両属性の所持装備に追加し、自動装着しない。素材・装備・石・保証カウントをまとめて保存する。星3以下の抽選で猟犬は追加しない。
- 拠点下部は仲間を含む5施設を同じ行に収め、狭い画面はアイコン＋短い名称に切り替える。説明は広い画面で表示する。

## 2026-10-19：猟犬ごとの育成・攻撃技・ミッション通知

### 育成の入口と保存

拠点の施設は「仲間／ミッション／刻印／図鑑」。仲間の編成カードの「育成・装備」からレベル上げ、攻撃・体力訓練、調律、装備の作成・着脱を行う。調律専用画面と工房の独立入口は撤去。刻印抽選・装着は既存の刻印画面を維持する。

`game/hound-growth.ts`が個別のlevel/xp/power/guard/attunementをprofile.growth[猟犬ID]に管理する。初回移行では所持済みの各猟犬に従来の属性枠の育成値を引き継ぐ。移行後の新規加入はLv.1・EXP0・訓練0・調律なし。既存のprofile.light/shadowは装備コンテナとして維持し、育成値は選択した猟犬から投影する。保存キーlightShadowSave、装備・素材・通貨・名前・進行は維持。

本編報酬の経験値は出発時に選んだ二匹にだけ加算する。待機中の猟犬は成長しない。従来どおり次レベルに必要な経験値は現在レベル×3。固定演習・追加探索・対人戦は元の報酬規則のまま。

素材育成：次レベルまで上げる費用は現在レベルと同数の影の結晶。攻撃訓練は金属片2＋訓練回数×2で攻撃+1。体力訓練は影の結晶2＋訓練回数×2で最大HP+2。調律は第3節クリア後に無料変更。追撃＝攻撃+1、守護＝防御+1、なしに戻すことも可能。装備の所持・着用は光／影の属性枠共有を維持し、育成画面に明記する。

### 追加攻撃技

本編・通常の追加探索では、通常攻撃・明暗操作・防御・連携に加え、以下の1系統を各猟犬が使える。全て共通チャージ2を消費して技行動を終了する。敵だけを攻撃し味方は傷つけない。固定演習・固定試練と対戦／レイド専用盤の固定ルールは維持。

|技|猟犬|対象と効果|
|---|---|---|
|薙ぎ払う牙|黎明・アウル|隣接した方向の前方横3マス。通常攻撃相当の威力|
|貫く咆哮|ノクス・セレネ|縦横の直線3マスを貫通。攻撃+1|
|命喰らいの牙|宵・フェン|射程2の単体攻撃。ダメージを与えたら自身のHPを最大2回復|
|星火の炸裂|レグルス・イグニス|射程3の着弾点と隣接4マス。攻撃-1（最低1）|

`game/hound-skills.ts`が技の割当・対象範囲・攻撃値を定義。プレビューと発動は同じ計算を利用する。遮蔽物・低い壁・地形の射線を参照し、直線攻撃は壁で止まる。影の猟犬は最強光のマスを技の対象に含めない。新技は遮蔽物を壊さず、従来の通常攻撃で破壊する。技選択時に攻撃可能な敵を赤枠、狙った範囲を盤面に表示する。

### ミッション

拠点に独立したミッションボタンを置き、受取可能な未受取ミッションが1件以上ならアイコン右上に通知点を表示する。件数はボタンの読み上げラベルにも含める。受取後は共通ルールで件数を再計算し、全て受取済みなら点を消す。

## 2026-10-19：固定ヘッダー・独立ガチャ・敵の造形

- 仲間画面は固定したhub-fixed（見出し・閉じる・タブ・通知）とスクロールするhubContentに分割。PC・縦横画面で上部操作を維持する。育成や対戦の内容はスクロール領域内に表示。
- リザルトの「仲間を育てる」ボタンを削除。仲間の育成は拠点の「仲間」から行う。
- 猟犬召喚と刻印召喚を独立したガチャ画面（ui/gacha-hub.ts）へ統合。拠点の「ガチャ」から種類を切替。仲間の召喚タブと、施設タブの旧刻印画面を撤去。
- 猟犬の結果はgachaResultDialog、刻印の結果は既存のsigilRevealDialogで表示。結果から前回と同じ回数をもう一度引ける。回数・必要通貨を表示し、不足時はボタンを無効にする。刻印の交換結果は抽選ではないため再抽選ボタンを表示しない。
- 既存の排出率、星5保証、刻印保証、重複変換、指名交換、通貨、保存キーは維持。ゲームルールをUIへ複製せずroster.ts / expansion.tsの既存の抽選・付与処理を呼ぶ。抽選結果は表示前に保存する。
- 刻印の装着は仲間の育成画面へ移動。選択中の装備に対して所持刻印を付け外しでき、他装備で使用中の個数は既存socketSigilで検証する。
- enemy-detail.jsで傭兵の面頬・胸甲・肩甲・盾・刃・すね当て、ゴブリンの眉・鼻・牙・皮革・鉈、竜の鱗・翼膜・翼骨・歯・爪、喰らいの仮面・王冠・肋骨・光輪・外套を追加。竜の首・脚・尾は曲線に沿った関節と筋肉の量感へ変更。光影の配色と陰陽の装飾を使い分ける。
- 自作の手続き生成を継続し、外部モデル・素材・依存の追加はない。戦闘と図鑑は同じ造形を使う。敵の行動・能力・命中・床・保存データは変えない。
