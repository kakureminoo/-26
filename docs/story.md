# 光と影の猟犬 — 奪われた光と影

2026-10-18のユーザー指定を反映した現行設定。以前の「失踪した育て親を迎えに行く」「城の炉に閉じ込められた記憶」の筋書きは、この設定に置き換える。ゲーム本文の正本は `src/game/story.ts`。

## 始まりと二匹の動機

二匹は、住民から食事を分けてもらい、名前を呼ばれ、子どもたちと過ごしていた猟犬だった。突如として光喰らいと影喰らいが現れ、それぞれ光と影を喰らって支配を広げる。光を失えば作物が育たず、影を失えば人も生き物も休めない。二匹は世界に残された光と影から力を授かり、自分たちの居場所を守ってくれた住民の暮らしを取り戻すために旅立つ。

「残された光と影が力を授けた」という授与元、作物・休息への影響、支配核という呼称は、指定された設定をゲームにつなぐための補足創作。

## 城が敵に従う理由

各地の城は、領地の光と影の均衡を維持してもらう条件で二体に従い、光と影を差し出している。住民を守るための服従だが、取り立ては増え続ける。傭兵は城の契約に従って要所を守る一方、城も住民も解放を望んでいる。城を滅ぼすことではなく、均衡を維持するための服従を不要にすることが目的となる。

## 攻略の流れ

| 章 | 要所と守り手 | 解放時の実際の効果 |
| --- | --- | --- |
| 都 | 灯台／ボスゴブリン（既存ID `boss`） | 光の猟犬「灯の牙」：攻撃+1 |
| 森 | 祭壇／黒竜（`forest-heart`） | 影の猟犬「影の牙」：攻撃+1 |
| 白夜 | 集光炉／白竜（`sun-heart`） | 常闇の深淵へ進める。追加の恒久能力補正はなし |
| 常闇 | 水門／黒竜（`abyss-heart`） | 暁封じの城へ進める。追加の恒久能力補正はなし |
| 城 | 中枢／陰陽の守兵（`castle-eclipse`） | 二匹「解放の守り」：防御+1 |
| 最終決戦 | 光喰らい・影喰らい（`castle-heart`） | 二体とも倒すと世界を解放 |

敵は要所の支配核を通じて光と影を集め、猟犬の力も封じている。要所を解放するたび、力が土地と二匹へ戻る。敵の支配域が縮まり、最終ボスへの供給が減る。未解放の要所一つにつきボスの追加HP12・威力1として定義し、三か所の解放で追加値は0になる。通常の進行では三か所を解放するまで最終戦へ出発できず、強化状態のボスへ挑戦するモードはない。

灯芯回収は奪われた力の回収、救助は住民の保護と要所の情報収集、討伐は支配核への道を開く行為。光だけを増やしても影を消しても、均衡は戻らない。戦闘で互いが使える明暗の道を残す判断と、世界に両方を取り戻す目的を一致させる。

## 敵の構成

白・黒の傭兵、白・黒のゴブリン、ボスゴブリン、白竜・黒竜、陰陽の上位敵、最後の二体を配置する。種族と属性は名前・造形のメタデータ、行動種別は既存の戦術ルールとして分離する。白黒の属性そのものに新しい耐性倍率は追加していない。

最終戦では影喰らいが夜蝕、光喰らいが白灼を奇数ラウンドに予告し、偶数ラウンドは通常行動する。両方が同時に予告されたときは封印陣が共通の退避先になる。敵を倒すとその敵の予告は中止する。護衛の全滅は最終戦の条件に含めない。

| 攻撃案 | 現状 |
| --- | --- |
| 明るさや封印陣で防ぐ広範囲技 | 実装済み：夜蝕・白灼 |
| 明暗に依存しない範囲への攻撃 | 既存の固定射線攻撃などを継続。新しい面状攻撃は未追加 |
| 猟犬の位置を変える | 実装済み：転位 |
| 発動までに設置物を壊して阻止 | 今後の拡張案。予告と実命中の共通判定への組込みが必要 |
| 床にダメージ罠を設置 | 今後の拡張案。移動中の命中と避難ガイドの対応が必要 |

## 伝え方とチュートリアル

初回は「名前を呼ぶ声／奪われた光と影／二匹に託された力／いつもの声がする場所へ」の4場面の専用序章を表示する。自動送りはせず、次へ・戻る・常時スキップを用意。終了またはスキップを既存保存キー内の `introSeen` に記録する。旅の記録から再生可能。進行済みのセーブには初回序章を強制表示しない。画像は未作成で、現在は光・影の記号による仮表示。

チュートリアルは本編最初の「薄明の遺跡」と共通。未達成の初回に短い操作ガイドを表示し、「クエスト」内のチュートリアルから再出発できる。独立したTRAININGの入口と訓練場の施設は削除。旧演習の固定配置の定義は比較・回帰検証用として残す。

本編は5章25クエスト。追加10件を森と城の間へ配置し、既存15クエストのID、報酬、保存キーを維持。旧達成済みの城は再挑戦可能だが、新しい物語の次の目的は白夜からとなる。クリア記録から解放効果を算出し、再クリアで重複加算しない。過去に最終戦をクリア済みの記録は再挑戦を許可する。結末では二体を倒して光と影が戻り、城は服従の必要を失い、住民が二匹の名前を呼んで迎える。

## 2026-10-19：仲間と三段階

本編の各クエストは前哨戦・増援・最終目標に分かれる。物資・救助対象と要所は最後の段階で解放される。灯台bossの達成で光の猟犬「城衛のアウル」、森のforest-heart達成で影の猟犬「森守のノクス」が加入し、結果画面に加入を表示する。既にその要所を攻略済みの保存にも加入を反映する。元の二匹を失ったり、育成をリセットしたりはしない。
