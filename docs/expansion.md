# 冒険・刻印・図鑑・高低差

2026-10-18追加。既存15クエストのIDと保存キー `lightShadowSave` を維持し、その中の `expansion` に追加データを保存する。新規開始時の欠片は0。旧クリア済みの要所の遺物は図鑑へ移行するが、過去の勝利を通貨へ換算しない。

## 刻印

通常クエスト成功で灯の欠片2個。追加ステージは初回6個、再クリア2個。失敗・撤退・チュートリアル演習では付与しない。追加ステージでは本編の経験値・素材・ランク・勝利数・本編の進行を変更しない。戦闘中の中断保存は追加していない。

1回3欠片、10回30欠片。通常時の提供割合は以下。通常が9回続くと10回目は希少以上から重み付きで抽選（希少各10/34、伝説各2/34）。希少以上で保証カウンタをリセット。10回抽選は費用と乱数を全て検証してから一括で保存する。演出の途中で閉じても取得結果は保持する。

| 刻印 | 確率 | 効果 |
| --- | --- | --- |
| 残火／通常 | 23% | 明るさ3〜4で攻撃+1 |
| 夜牙／通常 | 23% | 明るさ0〜1で攻撃+1 |
| 堅石／通常 | 20% | 防御+1 |
| 息吹／希少 | 10% | 最大HP+2 |
| 風歩／希少 | 10% | 移動力+1 |
| 双極／希少 | 10% | 明るさ0または4で攻撃+2 |
| 明星／伝説 | 2% | 開始チャージ+1、明るさ3〜4で攻撃+1 |
| 宵翼／伝説 | 2% | 移動力+1、明るさ0〜1で回避+15ポイント |

重複は所持数に加え星屑を獲得する（通常1／希少3／伝説8）。星屑8／16／32で各レアリティの任意の刻印と交換する。選択した刻印と進捗を表示し、交換では所持品を失わない。旧データの所持数・装着・欠片・保証カウンタを引き継ぎ、新しい星屑は0から開始する。8種それぞれにオリジナルの刻印図案を表示する。開封演出は希少度別に変え、「まとめて見る」と演出軽減にも対応する。これらが楽しさを改善するかのユーザー評価は未実施。

装備ごとに1枠。1個の刻印は二匹を通して1枠で使用し、重複分は別の枠へ付けられる。外した装備の枠も使用数に含むため、移すときは先にその枠から外す。付け外しは無料。能力は実際に装着中の装備の刻印だけを参照する。出発時に写しを作り、戦闘の途中で拠点の装備設定を変更する操作は許可しない。課金、外部サービス、期間限定抽選はない。

## 冒険と試練（周回遠征を含む8形式）

「クエスト」内の「エンドコンテンツ」から選択。本編とは別の達成印を保存する。

| 内容 | 開放 | 達成条件・特徴 |
| --- | --- | --- |
| 連戦探索・双路の踏査 | 第1節 | 3波を全滅。HP・チャージを持ち越し、途中報酬・戦闘間回復なし。次の波で新しい行動順を選ぶ |
| 明暗パズル・調和の二つ印 | 第2節 | 8ラウンド以内に、光の猟犬を光印(5,4)の明るさ3以上、影の猟犬を影印(7,4)の1以下へ。同時に成立で達成 |
| 防衛戦・灯を絶やすな | 第3節 | 核(3,4)、耐久9を5ラウンド守る。第3ラウンドに増援。敵は核も固定予告の対象にできる |
| 制限依頼・壁なき救援路 | 第3節 | 遮蔽物設置禁止、6ラウンド以内の物資回収と帰還 |
| 戦術試練・陰陽の包囲 | 第4節 | 固定Lv1・HP光10/影9・装備/刻印/調律/要所能力なし、開始チャージ3。8ラウンド以内に敵3体を倒す |
| 再戦・喰らいし双極 | 最終戦クリア | 本編の育成と刻印を持込み、HP各36・威力7の二体を倒す。チャージ上限2で合体技は使用不可 |
| 高低差探索・見晴らしの砦 | 第5節 | 高台・階段・低い壁のある砦で敵3体を全滅 |

座標は内部の0始まり。制限ラウンド数は、そのラウンドの敵行動が終わるまでを含む。防衛は最後の敵行動で核または二匹が倒れた場合、成功にしない。連戦の増援地点に猟犬などがいる場合、同じマスに重ねず、近い空き床へ配置する。チュートリアル `tactics` の固定能力・報酬なし・プロフィール不変は従来どおり。

## 図鑑

装備8種は所有、刻印8種は抽選で取得、敵は本編・追加ステージの出発/増援時に遭遇、地域の遺物7種は対応ステージ初達成で登録する。未発見は名称と説明を隠し、各カテゴリに収集数を表示。遺物は図鑑用で、新たな装備能力は付けない。チュートリアル演習では遭遇登録もしない。

## 高さ

本編25ステージと演習の床は変更せず、新しい高低差探索だけに高さを導入する。

- 1段の見た目は0.48ワールド単位。高台はx6〜10、y2〜5。階段は(6,4)と(10,3)。
- 高低差をまたぐ歩行は、隣接するどちらかが階段の場合のみ可能。登りは従来の明るさコストに+1、下りは追加0。猟犬と徒歩の敵は同じ地形接続を使う。影の強光侵入禁止は維持。
- 猟犬の通常攻撃は、高い床から低い床の敵へ威力+1。対象ボタンの予測と実命中は同じ関数を参照する。合体技、挟撃、遮蔽物への攻撃、敵攻撃にはこの追加補正を付けない。
- 低い壁(7,3)、(9,4)は通れない固定地形。光源から床への高さ付きの線で、壁や高台に遮られる光を計算する。射撃の予告と命中も同じ遮蔽関数を使う。高さのある光源は低い壁を越えて照らせる場合がある。
- 床の色・数値がゲーム上の明るさ。GPUの装飾用シャドウと明るさ計算は役割が異なる。ルールの高さは1段の離散値であり、任意角度の物理シミュレーションではない。
- 床・犬・敵・灯火・予告の表示とクリック判定を同じ高さに合わせる。ワープ/転位/強光による退避は徒歩ではないため階段を要求しない。

この拡張の画面の図形、刻印記号、高台・階段・低い壁は既存の描画機能で作成した。
